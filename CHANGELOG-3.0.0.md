# NEXORA 3.0.0

- Tambah Android Equalizer, BassBoost, Virtualizer, stereo pan dan orbit 8D sederhana untuk Native Player.
- Tambah Visualizer FFT native yang diaktifkan secara eksplisit oleh pengguna.
- Tambah pembacaan metadata dan album art tertanam dari URI media.
- Tambah editor metadata lokal (sidecar) dan editor lirik LRC dengan sinkronisasi.
- Tambah PiP Android melalui Activity dan penyempurnaan mode PiP WebView.
- Tambah sistem impor plugin scraper JS pilihan pengguna dengan batas ukuran file.
- Batasi pemindaian MediaStore sampai 1.500 item per pemindaian.
- Pertahankan scraper bawaan, alur unduh otomatis, package `nx.app`, dan UI tanpa framework besar.
- Naikkan versi menjadi 3.0.0 / versionCode 8.

Catatan: build Android SDK dan pengujian perangkat fisik masih diperlukan sebelum rilis produksi.
